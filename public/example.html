🗺️ Embedded Helsinki Map — example

This page shows a map produced by the Helsinki Map Embed Builder, embedded with a plain <iframe>.

Live embedded map

Map data © City of Helsinki — source kartta.hel.fi.

The snippet used above

<iframe width="640" height="460"
        style="border:0; width:100% !important; height:460px !important;"
        frameborder="0"
        src="https://kartta.hel.fi/embed/?minimap=1&maptools=1&setlanguage=en&link=0evBZiu"
        title="Helsinki Map Service"></iframe>

Replace link=0evBZiu with a code generated by the builder (or by POST /api/embed) to embed your own view.
