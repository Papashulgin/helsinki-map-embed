# Telinekonttorin kuvat ja grafiikka

Lisää uudet käyttöliittymän kuvat tähän hakemistoon aiheensa mukaiseen
alikansioon. Tiedostot palvellaan suoraan `public-static`-juuresta, joten
esimerkiksi `logos/telinekonttori/logo.svg` viitataan sivulta osoitteella
`assets/logos/telinekonttori/logo.svg`.

| Hakemisto | Sisältö |
| --- | --- |
| `logos/` | Telinekonttorin, kumppanien ja valmistajien logot |
| `icons/` | Pienet käyttöliittymän symbolit ja tilamerkit |
| `ui/` | Osoittimet, ohjaimet ja muut käyttöliittymägrafiikat |
| `illustrations/` | Kuvitukset, työvaiheet ja opastusgrafiikka |
| `backgrounds/` | Tausta- ja kansikuvat |

Käytä selkeitä pieniä tiedostonimiä, kuten `logo-color.svg` tai
`empty-project.webp`. Suosi SVG:tä logoille ja ikoneille sekä WebP:tä tai
optimoitua PNG:tä rasterikuville. Pidä alkuperäiset kuvat täällä ja kirjaa
ulkopuolisen aineiston lähde sekä käyttöoikeus samaan hakemistoon lisättävään
`ASSET-NOTES.md`-tiedostoon.

Nykyisiä sivuja käyttävät kuvat säilytetään alkuperäisissä poluissaan
yhteensopivuuden vuoksi. Uusi kansiorakenne ei siirrä tai nimeä niitä
automaattisesti.
